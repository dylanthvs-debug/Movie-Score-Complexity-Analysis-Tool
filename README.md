# Movie-Score-Complexity-Analysis-Tool
A single tool that takes an audio file as input and produces a quantifiable complexity rating for that musical composition.
<br>
<br>
## Background
Movie Scores are complex pieces of music that are composed of several different instruments playing music simultaneously as others. In order to generate a viable complexity score, the music must be broken down into its individual components, and metrics such as the melodic complexity, rhythmic complexity, and harmonic complexity of the soundtracks can then be quantified.
<br>
